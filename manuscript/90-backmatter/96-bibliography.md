# Bibliography

This chapter is rendered from [`manuscript/bibliography.bib`](../bibliography.bib)
via Pandoc's citation processing (`pandoc --citeproc`) as part of the
`make book` build. It is not maintained as prose here — add or edit
entries in the `.bib` file directly, and cite them elsewhere in the
manuscript with `[@bibtexkey]`.

See `AUTHORS-GUIDE.md` section 3: every citation's key must exist in
`bibliography.bib` in the same commit that introduces it.
