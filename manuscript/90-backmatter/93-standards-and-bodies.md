# Standards and Bodies

Which organization publishes or stewards each standard or terminology
referenced in this book, and its role in one line. See
[Part IV](../40-part-4-reference/) for dated, detailed entries.

| Standard / System | Publisher | Role |
|---|---|---|
| HL7 v2, v3/RIM, CDA, FHIR | HL7 International | Base messaging and document/resource standards |
| SNOMED CT | SNOMED International | Clinical terminology (conditions, procedures, findings) |
| LOINC | Regenstrief Institute | Terminology for observations and lab tests |
| RxNorm, UMLS | US National Library of Medicine (NLM) | Drug terminology; cross-terminology meta-thesaurus |
| ICD-10/ICD-11 | World Health Organization (WHO) | International diagnosis/mortality classification |
| ICD-10-CM/PCS (US clinical modification) | Centers for Medicare & Medicaid Services (CMS) | US clinical/procedural coding modification of ICD |
| CPT | American Medical Association (AMA) | Procedure coding terminology |
| OMOP Common Data Model | OHDSI | Observational health data model for research |
| IHE profiles (PIX/PDQ, XDS, ...) | IHE (Integrating the Healthcare Enterprise) | Cross-standard interoperability integration profiles |
| Base XML / document tooling lineage | NEMA, ASTM | Historical standards bodies contributing to CDA's lineage and document standards generally |
