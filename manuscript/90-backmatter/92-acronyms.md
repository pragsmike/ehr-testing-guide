# Acronyms

Expansions only; see the [Glossary](91-glossary.md) for concept-level
definitions and [Standards and Bodies](93-standards-and-bodies.md) for
publishers.

| Acronym | Expansion |
|---|---|
| HL7 | Health Level Seven |
| OSI | Open Systems Interconnection (networking model; the "seven" in Health Level Seven is its application layer) |
| FHIR | Fast Healthcare Interoperability Resources |
| CDA | Clinical Document Architecture |
| C-CDA | Consolidated CDA |
| CCD | Continuity of Care Document |
| CCR | Continuity of Care Record |
| ASTM | American Society for Testing and Materials (now ASTM International; original publisher of CCR) |
| RIM | Reference Information Model |
| OBX | Observation/Result segment (HL7 v2) |
| OBR | Observation Request segment (HL7 v2) |
| CWE | Coded With Exceptions (HL7 v2 datatype) |
| NM | Numeric (HL7 v2 datatype) |
| ST | String (HL7 v2 datatype) |
| MSH | Message Header segment (HL7 v2) |
| PID | Patient Identification segment (HL7 v2) |
| EVN | Event Type segment (HL7 v2) |
| ORU | Observation Result (unsolicited) message type (HL7 v2) |
| ORM | Order Message (general order) message type (HL7 v2) |
| ADT | Admit/Discharge/Transfer message type (HL7 v2) |
| SNOMED CT | Systematized Nomenclature of Medicine -- Clinical Terms |
| LOINC | Logical Observation Identifiers Names and Codes |
| ICD | International Classification of Diseases |
| CPT | Current Procedural Terminology |
| RxNorm | (normalized names for clinical drugs; not itself an acronym expansion beyond the name) |
| CVX | Vaccines Administered (CDC code system identifying vaccine products) |
| MVX | Manufacturers of Vaccines (CDC code system, paired with CVX in immunization messages) |
| NDC | National Drug Code (FDA drug product identifier) |
| UCUM | Unified Code for Units of Measure |
| UMLS | Unified Medical Language System |
| UTS | UMLS Terminology Services (NLM's sign-up and access platform for UMLS) |
| CUI | Concept Unique Identifier (UMLS Metathesaurus concept key) |
| NLM | National Library of Medicine (US; steward of UMLS, RxNorm, and the SNOMED CT US Edition) |
| openEHR | (an open standard for EHR data and archetype modeling; not itself an acronym expansion beyond "EHR," included here alongside RxNorm's precedent) |
| OMOP | Observational Medical Outcomes Partnership |
| OHDSI | Observational Health Data Sciences and Informatics |
| NEMA | National Electrical Manufacturers Association (publisher of DICOM) |
| DICOM | Digital Imaging and Communications in Medicine |
| X12 | ASC X12, Accredited Standards Committee X12 (EDI standard; used for healthcare claims transactions) |
| IHE | Integrating the Healthcare Enterprise |
| XDS | Cross-Document Sharing (IHE document-sharing profile family) |
| PIX/PDQ | Patient Identifier Cross-referencing / Patient Demographics Query (IHE profiles) |
| ATNA | Audit Trail and Node Authentication (IHE profile) |
| ONC | Office of the National Coordinator for Health Information Technology |
| CQL | Clinical Quality Language |
| BX | Bidirectional Transformations (research literature abbreviation) |
| IG | Implementation Guide |
| MLLP | Minimal Lower Layer Protocol |
| CQRS | Command Query Responsibility Segregation (the read/write separation Chapter 32 maps the event log onto) |
